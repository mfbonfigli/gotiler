<div class="gt-column">

<Steps>

1. **Install** gotiler with the command for your platform, or download an archive from the [latest release](https://github.com/mfbonfigli/gotiler/releases/latest).

   <div class="gt-steady-tabs">

   <Tabs syncKey="install">
   <TabItem label="Linux and macOS">

   ```bash
   curl -fsSL https://github.com/mfbonfigli/gotiler/releases/latest/download/install.sh | sh
   ```

   </TabItem>
   <TabItem label="Windows">

   ```powershell
   irm https://github.com/mfbonfigli/gotiler/releases/latest/download/install.ps1 | iex
   ```

   </TabItem>
   </Tabs>

   </div>

2. **Tile** a file or a whole folder. Pass `--preview` to see the output right away in a local CesiumJS viewer and fine-tune its position.

   <div class="gt-steady-tabs">

   <Tabs>
   <TabItem label="Basic Usage">

   ```bash
   # Tile a LAS, LAZ, E57 or PLY file into ./out
   gotiler pcloud -o ./out ./input.las

   # Tile every file of a folder into its own tileset
   gotiler pcloud -o ./out ./las_folder

   # Merge a folder into one tileset, packed as a .3tz archive
   gotiler pcloud -o ./out --join --3tz ./las_folder
   ```

   </TabItem>
   <TabItem label="Gaussian Splats">

   ```bash
   # Tile a Gaussian splat scene, then place it on the globe
   gotiler splat -o ./out ./scene.ply

   # A scene trained with OpenCV axes, placed in Rome
   gotiler splat -o ./out --input-up-axis -y --longitude 12.4924 --latitude 41.8902 ./scene.ply
   ```

   </TabItem>
   <TabItem label="Custom CRS">

   ```bash
   # Set the input CRS, here with a vertical datum
   gotiler pcloud -o ./out -c EPSG:32633+3855 ./input.las
   ```

   </TabItem>
   <TabItem label="Colorize">

   ```bash
   # Color points by elevation
   gotiler pcloud -o ./out --colorize z:viridis ./input.las

   # Color by intensity on a reversed, 8-band turbo ramp
   gotiler pcloud -o ./out --colorize intensity:turbo:reverse:steps=8 ./input.las
   ```

   </TabItem>
   <TabItem label="Preview and Place">

   ```bash
   # Tile, then check the result on a globe
   gotiler pcloud -o ./out --preview ./input.las

   # Tile a Y-up model without a CRS, then move it into place
   gotiler pcloud -o ./out --crs local --input-up-axis y --preview ./model.ply

   # Open an existing tileset
   gotiler view ./out
   ```

   </TabItem>
   </Tabs>

   </div>

</Steps>

<Split>

- **Search an address**, or click **Pick position** and then the globe, to move the model there.
- **Drag the gizmo's** arrows and rings, or type offsets and rotations.
- **Save position** writes the new root transform into `tileset.json`, without rewriting the tiles.
- The viewer only listens on `127.0.0.1`, behind a random access token.

```bash
gotiler view ./out
```
