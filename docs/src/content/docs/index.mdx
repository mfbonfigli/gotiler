<Steps>

1. **Download** gotiler CLI from the [latest release](https://github.com/mfbonfigli/gotiler/releases/latest).

2. **Unzip it anywhere.** Keep the executable next to its `share` folder.

3. **Tile** a file or a whole folder. Pass `--preview` to see the output right away in a local CesiumJS viewer and fine-tune its position.

</Steps>

<div slot="aside">

<Tabs>
<TabItem label="Basic Usage">

```bash
# Tile a LAS, LAZ, E57 or PLY file into ./out
gotiler -o ./out ./input.las

# Tile every file of a folder into its own tileset
gotiler -o ./out ./las_folder

# Merge a folder into one tileset, packed as a .3tz archive
gotiler -o ./out --join --3tz ./las_folder
```

</TabItem>
<TabItem label="Custom CRS">

```bash
# Set the input CRS, here with a vertical datum
gotiler -o ./out -c EPSG:32633+3855 ./input.las
```

</TabItem>
<TabItem label="Colorize">

```bash
# Color points by elevation
gotiler -o ./out --colorize z:viridis ./input.las

# Color by intensity on a reversed, 8-band turbo ramp
gotiler -o ./out --colorize intensity:turbo:reverse:steps=8 ./input.las
```

</TabItem>
<TabItem label="Preview and Place">

```bash
# Tile, then check the result on a globe
gotiler -o ./out --preview ./input.las

# Tile a Y-up model without a CRS, then move it into place
gotiler -o ./out --crs local --input-up-axis y --preview ./model.ply

# Open an existing tileset
gotiler view ./out
```

</TabItem>
</Tabs>

<Split>

- **Search an address**, or click **Pick position** and then the globe, to move the model there.
- **Drag the gizmo's** arrows and rings, or type offsets and rotations.
- **Save position** writes the new root transform into `tileset.json`, keeping a backup of the original.
- The viewer only listens on `127.0.0.1`, behind a random access token.

```bash
gotiler view ./out
```

func main() {

}
