`--colorize` accepts 36 ramps from freely licensed sources: matplotlib, seaborn, cmocean, Fabio Crameri's Scientific Colour Maps and ColorBrewer (see [THIRD-PARTY-LICENSES.md](https://github.com/mfbonfigli/gotiler/blob/v3/THIRD-PARTY-LICENSES.md) for attributions). Good starting points: `viridis` for elevation, `turbo` for intensity, `rdbu` with `stretch=minmax` for change detection, `las-classification` for class codes. [Colorizing points](/gotiler/guides/colorizing/) explains how to apply them.

## Perceptually uniform

The safest default choices: equal steps in the data look like equal steps in color, so the ramp adds no bands or edges of its own.

| Ramp | Preview | Best for |
| ---- | ------- | -------- |
| <Ramp names="viridis" /> | <Ramp names="viridis" swatch /> | General-purpose elevation or continuous density; the scientific standard.                         |
| <Ramp names="viridis-pastel" /> | <Ramp names="viridis-pastel" swatch /> | A soft, pastel take on viridis that keeps its perceptual ordering.                                |
| <Ramp names="magma inferno plasma" /> | <Ramp names="magma inferno plasma" swatch /> | Heat-like sequential data with a dark-to-bright look.                                             |
| <Ramp names="cividis" /> | <Ramp names="cividis" swatch /> | Optimized for color-vision deficiency.                                                            |
| <Ramp names="turbo" /> | <Ramp names="turbo" swatch /> | Vibrant rainbow alternative to "jet" with tuned lightness; great for intensity and edge spotting. |
| <Ramp names="batlow" /> | <Ramp names="batlow" swatch /> | Colorblind-safe multi-hue rainbow alternative (Crameri); ideal for canopy-height models.          |

## Diverging change detection

| Ramp | Preview | Best for |
| ---- | ------- | -------- |
| <Ramp names="rdbu" /> | <Ramp names="rdbu" swatch /> | The gold standard for change: red = loss/erosion, blue = gain/accumulation. |
| <Ramp names="brbg" /> | <Ramp names="brbg" swatch /> | Brown-to-blue-green; bare soil versus vegetation/water shifts.            |
| <Ramp names="coolwarm" /> | <Ramp names="coolwarm" swatch /> | Balance-adjusted blue-to-red that tolerates hillshading and shadows.      |
| <Ramp names="spectral" /> | <Ramp names="spectral" swatch /> | Full-spectrum diverging ramp for deviations from a baseline.              |
| <Ramp names="balance" /> | <Ramp names="balance" swatch /> | Perceptually uniform blue-white-red (cmocean) with a truly neutral center. |

## Categorical classification

| Ramp | Preview | Best for |
| ---- | ------- | -------- |
| <Ramp names="las-classification" /> | <Ramp names="las-classification" swatch /> | ASPRS LAS class codes with their conventional colors (fixed 0–255 scale). |
| <Ramp names="dark2" /> | <Ramp names="dark2" swatch /> | Distinct muted dark tones; urban feature separation.                      |
| <Ramp names="paired" /> | <Ramp names="paired" swatch /> | Light/dark hue pairs; nested classes like low vs. high vegetation.        |
| <Ramp names="set2" /> | <Ramp names="set2" swatch /> | Pastel palette that keeps overlaid labels legible.                        |
| <Ramp names="accent" /> | <Ramp names="accent" swatch /> | Makes selected categories pop against neutral basemaps.                   |

Categorical ramps map equal-width value bands to discrete colors: combine them with `stretch=minmax` (or data with a known range) so category codes land on stable bands. `las-classification` needs nothing extra, as it is pinned to the absolute 0–255 class range.
