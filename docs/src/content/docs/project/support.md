gotiler is an AGPLv3 open-source project maintained with love. If it saves you time or resources, there are a few ways to help:

- **Make a donation** on [Ko-fi](https://ko-fi.com/mfbonfigli) to support ongoing maintenance and development.
- **Star the repository** on [GitHub](https://github.com/mfbonfigli/gotiler), so more people find it.
- **Report bugs and ideas** in the [GitHub issues](https://github.com/mfbonfigli/gotiler/issues), with the command you ran and, when you can, a small sample file.
